Team Task Manager
**About**

Team Task Manager is a web application that helps small teams create projects, assign tasks, track progress, and manage deadlines in one place.

**Features**

User Signup and Login
Create and Manage Projects
Add and Remove Team Members
Create and Assign Tasks
Update Task Status
Set Task Priority and Due Dates
Search and Filter Tasks
Track Overdue Tasks
Add Comments
View Project Dashboard

**User Roles**
Owner: Manages projects, team members, and tasks.
Member: Views projects, manages tasks, and adds comments.

**Technologies Used**
Frontend: React.js, JavaScript, HTML, CSS
Backend: Node.js, Express.js
Database: MongoDB

**Installation**
bash
git clone https://github.com/KARTHIKA7831/team-task-manager.git
cd team-task-manager

Install dependencies and start the frontend and backend servers.

**Project Goal**

To make team collaboration easier by organizing projects, tasks, and team activities in one place.
